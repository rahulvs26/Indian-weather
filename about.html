About this project

An interactive study aid for Indian monsoon weather and hydrology. It is built on published data from the India Meteorological Department, the Central Water Commission, WRIS and open sources â€” and it is explicit, on every figure, about what is real, what is measured here, and what is invented to make a mechanism visible.

The one rule this project is built around: nothing is asserted without a source, and anything that is not a source figure says so. If a number is derived, it is labelled (illustrative). If a source did not state something, the site says "not recorded in the sources used" rather than filling the gap with a plausible value.

3. Things this project is careful about

These are the places where an easy mistake would produce a confident wrong answer, and what is done instead:

  • A catchment is not a sub-basin tile. An early version showed Bhakra, on a 79 km river, a catchment of 19,937 kmÂ² â€” that was a whole sub-basin. Now every catchment comes from a real WRIS watershed unit, and where a watershed unit and the published dam catchment disagree, the published dam figure is shown and the discrepancy is named.
  • A river cannot flow both ways at once. A race between two code paths could draw a course twice, upstream and downstream. Fixed with a sequence token, so a stale response can never overwrite a newer one.
  • A river course follows the mapped channel. Courses are draped on real river geometry and simplified to a stated tolerance, never drawn as a straight line between two points.
  • Reservoir areas were in hectares. The source field is hectares; every card now also carries the published kmÂ² and the independently measured polygon area, because they differ by about 4 % and that difference is worth showing.
  • Heights you do not have are not invented silently. Where the CWC file has no dam height, a class median is used and the card says so.
  • Unknown is a valid answer. "not recorded in the sources used" appears wherever a figure could not be found, instead of an estimate wearing a real number's clothes.

4. Known limitations, stated plainly

  • The rainfall table is a 1901–2015 record mean, not the official 1971–2000 LPA. State values are area-weighted approximations across IMD subdivisions.
  • Phenomena sources are weaker than everything else. The 41 climate phenomena and the eight MJO phases cite sources as "web Â· Pai 2011" with no journal or page, so they cannot be checked from the deck. Every other number cites a PDF and a page. Re-sourcing these is open work.
  • Dam records are hand-compiled. A 39-entry table of published capacities and gate data, each figure carrying its own source URL. One row of 39 has been independently verified so far.
  • Visual layout has never been machine-checked. Every test here is arithmetic, structural or timing-based. Nothing in this project can see its own output, so how it looks is confirmed by people, not by tests.
  • State boundaries are coarser than they were. They are Natural Earth admin-1 at 10m, public domain, used so the repository can lawfully be published at all. The previous source forbade redistribution.

5. Build and run

No build step and no framework. Static files, two CDN libraries.

python -m http.server 8000
# open http://localhost:8000   (data fetches need http, not file://)

Tests:

node data/_run_tests.mjs     # 7 suites
node data/_smoke.mjs          # 54 static checks: wiring, contracts, payload, rights notices
node data/_gen_india_states.mjs   # rebuilds the public-domain boundaries; aborts if a key breaks
